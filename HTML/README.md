# HTML Study Notes

A clean, GitHub-friendly HTML study guide based on **Session 1**, **Session 2**, and the provided HTML interview revision sheet.

## 📚 Files

| File | Purpose |
|---|---|
| [`HTML_Notes.md`](HTML_Notes.md) | Full explanation + examples + quick revision tables |
| [`HTML_Interview_QA.md`](HTML_Interview_QA.md) | Interview questions **with answers for every question** |

## 🧭 Recommended Study Order

1. Read `HTML_Notes.md` topic by topic.
2. Review the **Quick Revision** sections.
3. Open `HTML_Interview_QA.md`.
4. Try to answer each question yourself first, then open **Answer**.
5. Repeat the interview section before an interview.

- Images and `alt`
- Comments
- `<div>` and `<span>`
- Semantic HTML
- Media: image, audio, video, iframe
- Ordered, unordered, and description lists
- Tables
- Forms
- Input types
- Radio and checkbox grouping
- Form/input attributes
- Labels, select, textarea, datalist, button
- `action` and `method`
- `id` and `class`
- Complete HTML example
